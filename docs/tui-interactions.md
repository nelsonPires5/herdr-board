# TUI interaction contract

This is the behavior-preservation source of truth for the functional UI redesign. Every listed capability must remain available through its existing keyboard path. Mouse/touch-first controls may expose the same capability, but must dispatch the same reducer/effect path and must not add product features.

## Layout vocabulary

- **Compact:** terminal width `< 60`; board shows exactly one full-width column and a three-row mobile header (column switcher, running count, direct visibility filters). Sheets use all space above the footer and receive a clickable `[×]`.
- **Regular:** width `60..=119`; multi-column board and centered sheets.
- **Wide:** width `>= 120`; same interaction model as Regular, with more columns/space.
- Every layout reserves the bottom row for a footer: a transient toast, or (except on the board, whose action row already exposes `? Help`) a contextual hint. Toasts expire after more than four seconds.
- In the tables, **❌ no mouse parity** means the keyboard capability cannot be performed by a corresponding mouse control. “Partial” calls out narrower mouse support.

## Mouse-parity summary

Mouse support is intentionally narrow rather than a full alternative input path. Full or useful parity exists for visible board/card focus, board card scrolling, detail popup/fullscreen, detail comment selection/edit/delete/history, form Save/Cancel, Compact sheet close, and Compact switcher rows. The largest explicit parity gaps are:

1. No mouse activation for Regular/Wide board switching or template application.
2. No mouse entry controls for create/edit/archive/delete/move/filter/refresh/run actions.
3. Picker rows and confirmation yes/no choices are never clickable.
4. Form fields cannot be focused, edited, or cycled with the mouse (only Save/Cancel).
5. Runs cannot be selected by clicking their rows; `o` has no click action.
6. Help and Comment History do not wheel-scroll.
7. Compact’s one-column board makes cross-column card/column drag effectively unavailable; keyboard `H/L` and `M` remain the routes.
8. Card Detail has no clickable close control, even in Compact (unlike framed sheets).
